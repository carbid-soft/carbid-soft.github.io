Эластичный бустинг Ozon: почему уходит весь остаток и как отказаться

Отказаться можно в любой момент: убрать товар из акции и запретить Ozon добавлять его снова. Важно сделать это осознанно — с октября в такой акции участвует весь остаток. Подробный разбор настройки — в инструкции «Автодобавление в акции Ozon».

Коротко. Товар уже в акции — удалите его из участвующих в разделе акций (или методом API /v1/actions/products/deactivate). Чтобы Ozon не добавлял его снова — выключите «Автоматически добавлять товар в акции». Одно без другого не работает.

Что изменилось в октябре 2026

По данным SelSup, 28 сентября 2026 года Ozon объявил: с 6 октября в акциях «Эластичный бустинг» и «Скидка на сток» убирают колонку «Количество товаров по акции», к 20 октября — у всех продавцов. Товар в акции — значит, по акционной цене продаётся весь его остаток, а не часть, которую вы отдавали раньше. Комиссия и эквайринг считаются от сниженной цены, а логистика и себестоимость остаются прежними.

Как вывести товар из акции

  • В кабинете — откройте акцию в разделе акций и удалите товар из участвующих. Удалять товар из акции можно в любой момент.
  • Через API — метод /v1/actions/products/deactivate с номером акции и списком товаров: {"action_id": …, "product_ids": [ … ]}.

Как запретить Ozon добавлять товар снова

  1. Для всех товаров — в разделе обновления цен скачайте шаблон, в столбце автоматического добавления в акции поставьте «Нет», загрузите файл обратно.
  2. Для отдельных — переключатель «Автоматически добавлять товар в акции» в разделе «Цены на товары» или в приложении Ozon Seller.
  3. Через API — поле auto_add_to_ozon_actions_list_enabled со значением DISABLED в методе /v1/product/import/prices, вместе с текущими ценами товара.
Запрет автодобавления не выводит товар из акций, где он уже участвует. Он только не даёт Ozon добавлять товар в новые. Из текущих акций товар нужно убрать отдельно — шаг выше.

Не упадёт ли товар в выдаче

Ozon заявлял, что понижающих коэффициентов за запрет автодобавления нет. При этом включённая опция, по словам компании, даёт дополнительные 10 процентных пунктов к бустингу в поиске. Поэтому решение — по каждому товару: выдерживает ли он акционную цену на весь остаток с учётом комиссии, логистики и себестоимости. Прикинуть можно в калькуляторе маржи.
